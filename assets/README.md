# Assets

Platz für finale Grafiken, Klänge, Schriften und Themes (Lastenheft 8.1):

```
assets/audio/   (music/, sfx/)
assets/fonts/
assets/sprites/ (environment/, items/, tools/, ui/, portraits/)
assets/themes/
```

Derzeit zeichnet und erzeugt das Spiel alle Grafiken und Klänge zur Laufzeit
(`scripts/item_shapes.gd`, `scenes/main/*_view.gd`, `scripts/sfx_synth.gd`).
Siehe Lastenheft Kapitel 12, Punkte 3 und 4.
