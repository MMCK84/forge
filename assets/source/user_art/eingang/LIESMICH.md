# Eingang für Original-Bilder

Hier die **Originaldateien** aus Midjourney ablegen (unverändert, z. B. PNG mit 2048 × 2048).
Dateiname = ID aus dem Prompt-Heft, z. B. `background_2.png`, `forge_clay.png`, `door_hinge.png`.

Hochladen auf GitHub: Branch `claude/sharp-rubin-jfnibw` wählen → diesen Ordner öffnen →
„Add file“ → „Upload files“ → Dateien hineinziehen → „Commit directly to the claude/sharp-rubin-jfnibw branch“ → „Commit changes“.

Claude holt die Dateien ab, prüft sie, sortiert sie in `backgrounds/`, `items/`, `machines/` usw. ein und leert den Ordner wieder.
